# Layout and Branding Fixes for Ruleta de Sorteo

Updated the project branding and fixed the critical layout issue where the wheel overlapped buttons. The header displays the full institution name "Universidad Nacional del Centro del Perú – Dirección de Proyección Social y Extensión Cultural" with improved logo visibility (increased from 55px to 75px). The wheel-box was restructured from flex-grow to fixed height (280px), ensuring the "Sorteo completo", "Uno a uno", and "¡Girar!" buttons remain visible and accessible without overlap.

**Watch for:** The wheel height is now fixed at 280px. This is fine for standard displays, but confirm that this constraint works as intended if the app is used on very small screens (tablets in portrait, older phones). No mobile responsiveness layers were added—that's acceptable for this scope, but flagged in case future versions target mobile.

**Verdict**: APPROVED

## High-level view

The title now appears in both the browser tab (index.html `<title>`) and the visible header (App.jsx), rendered across two lines with a line break for readability. Logos increased to 75px height, balancing visibility with header proportions and flexbox alignment.

The critical fix constrains the wheel-box to `flex: 0 0 auto` with explicit `height: 280px`, replacing the previous `flex: 1` that allowed unbounded expansion and hid the buttons. The spacing between the wheel and buttons is explicit (`margin-bottom: 0.5rem`), preserving the flex layout's gap. This approach keeps buttons always visible and clickable without requiring JavaScript or dynamic resizing.

The CSS grid layout (left panel with wheel, right panel with participant list) remains intact, as do the color scheme, visual hierarchy, and flex patterns throughout the rest of the interface.

## Branding and Header Visibility

The title updates serve distinct purposes: the browser tab title (index.html) is a single line with hyphen separator for SEO and searchability, while the visible header (App.jsx) splits across two lines with `<br/>` for readability. Logos increased from 55px to 75px with max-width adjusted to 160px, maintaining proportions while increasing visual weight. The flexbox `space-between` layout anchors logos left and right, centering the title between them.

## Wheel Layout and Button Accessibility

The issue was `.wheel-box` with `flex: 1`, which expands to fill available vertical space in a flex column, hiding the buttons below. The fix: `flex: 0 0 auto` with `height: 280px` fixes the wheel at a known size. The left panel layout is now: mode toggle (~40px) → wheel-box (280px) → spin button (~40px) → action buttons (~40px), with `margin-bottom: 0.5rem` between wheel and buttons to guard against flex gap collapse.

## CSS Structure and Responsive Considerations

CSS Grid handles two equal columns (50/50) with a 1rem gap. Within each panel, flex columns stack elements vertically. The fixed 280px wheel height works on standard desktop and tablet displays, but does not adapt to very small viewports—column stacking or font scaling for mobile would require additional media queries outside this scope.
